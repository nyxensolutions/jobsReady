# Launch Reels — Hindi (Instagram + Facebook)

Six reels to open the Jobs24India account. All Hindi. Shoot in one afternoon, publish over
the first two weeks. Companion to `social-media-playbook.md` and
`content-calendar-nov-2026.md`.

Cluster is written as **ओखला / Okhla** throughout. If Noida Sector 63 goes first, swap the
place name and the pincodes — nothing else changes.

## Format rules (all six)

| Thing | Spec |
|---|---|
| Size | 1080×1920, 9:16 |
| Length | 20–35 seconds. Nothing longer at launch. |
| Language | Spoken Hinglish, on-screen text in Devanagari |
| Subtitles | **Burnt in, Devanagari, always.** 85% watch muted |
| Hook | Place + number in the first 2 seconds |
| Audio | Own voice, light trending audio at 10–15% under it |
| Cover | 1:1 centre-safe — IG crops the grid thumbnail |
| End card | Logo + `jobs24india.com` + "नौकरी के लिए पैसे कभी नहीं" — 2 seconds, same on all six |
| CTA | "लिंक बायो में" on IG · "कमेंट में लिंक" on FB (FB throttles caption links) |

No intro animation, no "hello doston", no logo sting at the start. The first frame is the
hook or we lose them.

Shoot order: R1 and R2 together (same setup, founder on camera), then R3/R4 (screen
recording, no face), then R5 and R6.

## Shoot plan — one afternoon

**You need:** a phone (rear camera, 1080p60), a ₹400 clip-on mic (phone mic loses to
traffic noise — this is the one thing worth buying), daylight, and two locations: an Okhla
street and one small factory or shop front.

| Block | Reels | Time |
|---|---|---|
| 1 · Street, founder to camera | R1, R2, R5 talking parts | 60 min |
| 2 · Shop/factory front | R6 | 25 min |
| 3 · Desk, screen recordings | R3, R4, plus b-roll for R1 and R5 | 45 min |
| 4 · Edit | all six | 3–4 hours |

Do all three talking reels in one block, same shirt. Nobody notices and it saves a
second shoot day.

**Screen recordings:** record on a real phone, in Hindi (`/hi`), on the cluster page with
real jobs loaded — not a mockup, not desktop. The jobs on screen must be live listings;
somebody will check.

**Editing:** CapCut is fine. Burn in Devanagari subtitles, keep cuts under 3 seconds, no
transitions beyond a hard cut. Export 1080×1920, H.264.

---

## Publishing

- **Instagram:** upload as Reel, tick "Also share to Facebook". Cross-posting carries the
  caption but strips link formatting — put the link in the FB comment regardless.
- **Facebook Page:** for R6, upload natively to the Page instead of cross-posting. Native
  Page video reaches local business audiences better than a mirrored IG reel.
- **Shorts/Moj/ShareChat:** same file, same caption, within 24 hours. Zero extra cost.
- **Hashtags:** 8–12, in roman script even though the caption is Hindi — that is how people
  actually search. Keep this set, vary 2–3 per post:
  `#OkhlaJobs #DelhiJobs #NaukriDelhi #DeliveryJobs #WarehouseJobs #SecurityGuardJobs #JobsNearMe #FreeJobAlert #Jobs24India #NCRJobs`
- **First hour:** reply to every comment. Early comment velocity is most of the ranking.

**What tells us it worked:** shares and saves, not views. A reel with 4,000 views and 60
shares beats one with 20,000 views and 5. Shares are how this gets into the WhatsApp
groups where our seekers actually are.

## Automating later

`D:\Nyxen\olympiadready-social` already solves this: GitHub Actions cron, Meta Graph API,
filename-as-contract (drop a file at the expected path and it posts that; if missing, it
generates one). Copy the structure. Two differences for Jobs24India:

1. **Facebook as well as Instagram.** The OlympiadReady bot is Instagram-only. Facebook
   Page posting needs a separate Page access token and the Page's own publishing endpoint.
2. **Our content is database-driven, which OlympiadReady's is not.** R4 is the proof: the
   daily job-card reel and the daily carousel can be generated straight from live job
   rows — real titles, real salaries, real areas, filtered to verified employers in the
   active cluster. That is a genuinely better automated post than a quiz, because it is
   never stale and never fake.

Sensible first automated slots, once the manual reels have shown what works:

| Time (IST) | Format | Source |
|---|---|---|
| 08:00 | Job carousel, 6 jobs | generated from live jobs in the cluster |
| 13:00 | Job-card reel (R4 template) | generated, 5 jobs |
| 19:00 | Pillar 2/3/4 post | hand-made, dropped into the repo |

Keep the manual override: the trust and salary content is the reason the account works and
should stay hand-written.
